# HAURUX TECH STUDIO

## UI/UX & Product Systems Studio

**Complex work, made clear.**

We shape complex, data-heavy web applications into clear product systems. Our focus is the structure behind the interface: roles, workflows, decisions, exceptions, and the details developers need to build with confidence.

## Capabilities

- ERP and operations UX
- Workflow mapping and information architecture
- Role-aware interfaces and permission models
- Responsive and accessible interface design
- Design systems and developer handoff

## How We Work

1. **Discover** the goals, users, constraints, and operating context.
2. **Map** roles, information, workflows, states, and exceptions.
3. **Design** clear interfaces and a consistent product system.
4. **Validate** priority flows, responsive behavior, and accessibility.
5. **Handoff** implementation-ready specifications and assets.
